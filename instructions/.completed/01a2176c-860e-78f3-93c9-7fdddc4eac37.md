## 목표
새 프로젝트의 지침 작성(관리 블록)은 이미 있다. 남은 것은 초기화된 프로젝트의 지침 블록이 현재 구성으로 만든 내용과 다를 때(새 버전 TUI, `project.json`의 훅 제목 변경 등) 갱신하는 기능이다.

## 사용자 결정 (2026-11-26)
- 검증 화면에서 충돌이 없고 지침 블록이 다를 때 [지침 갱신] 버튼을 연다. 0026의 "스킬·훅 추가만 연다"에 이 기능 하나를 더한다.

## 범위
- 포함:
  - 검증 화면의 [지침 갱신]: 지침 파일(영/한)에 쓰기가 계획될 때만 보인다
  - 미리보기 후 적용. 미리보기에서 Esc를 누르면 쓰지 않고 검증 화면으로 돌아간다
  - 추가 화면에서 검증 화면으로 돌아올 때 원래 검증 결과를 되살린다
  - 수정: 검증이 훅 항목을 넘기지 않아 훅이 기록된 프로젝트가 늘 "다름"으로 보이던 문제
- 제외: 사용자가 고친 블록(충돌)은 다시 쓰지 않는다. 동적 스킬·참조 문서 안내(콘텐츠 서비스 계약 필요)

## 테스트
- 같은 구성이면 검증이 일치하고 버튼이 없다
- 훅 제목이 바뀌면 [지침 갱신]이 보이고, Esc는 쓰지 않으며, 적용하면 영/한 블록이 바뀌고 블록 밖 사용자 글이 남는다. 다시 실행하면 일치한다
