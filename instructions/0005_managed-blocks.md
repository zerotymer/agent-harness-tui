## 목표
기존 사용자 파일에 경계가 정해진 관리 블록을 삽입·갱신·검증한다. 지침 문서와 `.gitignore`가 공통으로 사용한다.

## 규칙 구분
- 아래 요구사항은 TUI가 **대상 프로젝트에 적용하는 제품 동작**이다. 이 저장소의 작업 규칙(`CLAUDE.md`, `.skills/`)과 혼동하지 않는다.
- 테스트는 임시 디렉터리에 대상 프로젝트를 만들어 검증한다. 이 저장소의 `instructions/`, `.gitignore`, 지침 파일을 픽스처로 쓰지 않는다.

## 선행 조건
- 0003 (0004와 병행 가능, 통합은 0004 완료 후)

## 범위
- 포함:
  - 마커 형식: 블록 ID가 있는 시작·끝 마커, 파일 종류별 주석 문법(Markdown, gitignore)
  - 삽입·갱신·무변경 판정, 블록 해시를 소유권 기록에 사용
  - 블록 밖 내용 보존 (줄바꿈 형식 CRLF/LF 포함)
  - 손상 마커(끝 마커 없음, 중복, 중첩, ID 불일치)는 충돌. 전체 파일 교체 금지
  - 반복 적용 시 블록 중복 없음
- 제외:
  - 블록 안에 들어갈 내용 생성 (0006, 0009)
