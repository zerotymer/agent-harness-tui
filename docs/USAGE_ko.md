# agent-harness-tui: 설치와 사용

`agent-harness-tui`는 실행한 프로젝트에 에이전트 하네스를 구성하는 터미널 마법사다. 지시서 폴더, 에이전트 지침(`AGENTS.md`, `CLAUDE.md`와 각 `_ko.md` 쌍), `.skills/` 아래의 공유 스킬, `.gitignore` 블록을 만든다. 모든 변경은 먼저 미리보기로 보여 주고, 사용자가 확인할 때만 쓴다.

이 문서는 1단계(최초 생성)를 다룬다. 이미 만든 하네스의 갱신은 2단계 기능이며 아직 제공하지 않는다.

## 설치

Linux·Windows·macOS용 실행 파일은 GitHub Release마다 올라간다(`.tar.gz`, Windows는 `.zip`). 함께 올라가는 `SHA256SUMS`로 파일을 확인할 수 있다. 또는 소스에서 빌드한다:

필요 조건: 안정 버전 Rust 툴체인. 1단계는 Rust 1.97.1, edition 2024로 빌드·테스트했다.

```sh
cargo install --path .          # ~/.cargo/bin에 `agent-harness-tui` 설치
# 또는
cargo build --release           # 실행 파일: target/release/agent-harness-tui
```

관리자 권한은 필요 없다. 네트워크는 위키 게이트웨이에서 스킬을 가져올 때만 필요하다.

## 실행

```sh
cd /path/to/your/project
agent-harness-tui
```

- 현재 디렉터리가 프로젝트 루트다. 상위 폴더를 찾지 않고, 브랜치를 바꾸지 않으며, `git init`을 실행하지 않는다.
- 표준 입력과 출력이 모두 대화형 터미널이어야 한다. 아니면 기다리지 않고 종료 코드 2로 바로 끝난다.
- `agent-harness-tui --version`은 버전을, `--help`는 사용법을 출력한다.

## 6단계

| 단계 | 하는 일 |
| --- | --- |
| 1. 루트·설정 | 프로젝트 루트를 확인한다. 이미 초기화된 프로젝트는 요약과 무변경 검증만 보여 준다(아래 참고). |
| 2. 경로·백로그 | 참조 문서 폴더(기본 `references/`)와 산출물 폴더(기본 `.output/`, 이름은 `.`으로 시작)를 정한다. 선택 사항인 `agent.db` 백로그 사용 여부를 고른다. 고정 경로는 목록으로 보여 주지만 바꿀 수 없다. |
| 3. 에이전트·배치 | Claude Code와 Codex 중 사용할 에이전트를 고른다. 에이전트마다 **복사**(에이전트가 찾는 위치로 스킬 복사) 또는 **참조**(지침에서 `.skills/` 안내) 중 하나를 고른다. 심볼릭 링크 배치는 이유와 함께 선택 불가로 표시된다. |
| 4. 소스·스킬 | 필요하면 프로젝트 안의 로컬 폴더나 위키 게이트웨이에서 스킬을 추가한다. "스킬 소스" 참고. |
| 5. 미리보기 | 모든 디렉터리와 파일을 생성·갱신·변경 없음·보존·충돌(CONFLICT)로 표시해 보여 주고, Git 경고도 함께 보여 준다. 아직 아무것도 쓰지 않은 상태다. |
| 6. 적용·결과 | 미리보기에서 Enter를 누르면 적용한다. 결과 화면에는 생성·갱신·변경 없음·보존 항목과 백업 폴더가 나온다. |

키: ↑↓ 이동, Space 선택, Enter 다음 단계(4단계에서는 선택한 버튼 실행), Esc 이전(첫 단계에서는 종료), Ctrl+C 취소, 입력 칸 밖에서 `q` 종료. PgUp/PgDn으로 미리보기를 스크롤한다. 경로와 이름 칸에는 한글을 입력할 수 있다. 창 크기가 바뀌면 화면이 맞춰지고, 80칸보다 좁으면 단계 목록이 한 줄로 접힌다.

## 생성되는 것

| 경로 | 용도 | Git |
| --- | --- | --- |
| `instructions/`, `instructions/.completed/` | 작업 지시서 (고정) | 추적 |
| `instructions/completed.log` | 완료 로그. 없을 때만 빈 파일로 만들고, 고쳐 쓰지 않음 | 추적 |
| `references/` (변경 가능) | 참조 문서 | 추적 |
| `.skills/<id>/` | 공유 스킬 패키지 | 추적 |
| `AGENTS.md`, `AGENTS_ko.md` (Codex) / `CLAUDE.md`, `CLAUDE_ko.md` (Claude Code) | 관리 지침 블록. 나머지 내용은 사용자 소유 | 추적 |
| `.claude/skills/<id>/`, `.agents/skills/<id>/` | 복사 배치를 고른 에이전트의 스킬 복사본 | 제외 (다시 생성됨) |
| `harness.toml`, `harness.lock.json` | 공유 설정과 확정된 가져오기 | 추적 |
| `.harness/state.json`, `.harness/backups/` | 로컬 적용 상태와 백업 | 제외 |
| `.output/` (변경 가능) | 생성 산출물. 다시 입력으로 읽지 않음 | 제외 |
| `.gitignore` | 위 제외 규칙을 담은 관리 블록. 사용자의 다른 규칙은 그대로 둠 | 추적 |

도구는 기존 파일을 `agent-harness:begin`으로 시작해 `agent-harness:end`로 끝나는 관리 블록 안에서만 바꾼다. 마커가 손상됐거나 사용자가 블록 안을 수정했다면 미리보기에서 충돌로 표시하고, 파일 전체를 다시 쓰지 않는다. 파일 형식은 [`references/HARNESS_STATE_CONTRACT_ko.md`](../references/HARNESS_STATE_CONTRACT_ko.md)에 정리되어 있다.

## 스킬 소스

- **로컬 폴더.** 프로젝트 안의 폴더(예: `vendor/skills`)를 쓴다. `SKILL.md`가 있는 하위 폴더가 각각 스킬이다. 동봉 파일은 복사만 하고 실행하지 않는다. 패키지 밖을 가리키는 심볼릭 링크는 거부한다. 프로젝트 밖 폴더는 공유 설정에 저장할 수 없으므로, 그런 스킬은 먼저 프로젝트 안으로 복사한다.
- **위키 게이트웨이(`md.zerotymer.net`).** 도구는 게이트웨이 `https://md-gw.zerotymer.net`에서 `GET /pages/by-uuid`로 읽는다.
  - **토큰:** 토큰을 담은 환경변수의 *이름*을 입력한다. 기본값은 `GATEWAY_TOKEN`이고, 셸에 이미 설정한 다른 이름을 써도 된다. 토큰 값 자체는 파일·화면·로그에 남지 않는다.
  - **조회:** 페이지 UUID를 입력하고 [조회]를 누른다. 네트워크는 그때만 쓴다. 요청은 15초가 지나면 시간 초과로 끝나며, 응답이 올 때까지 화면이 갱신되지 않는다.
  - **내용:** 영문·한국어 페이지를 가공 없이 `SKILL.md`, `SKILL_ko.md`로 저장한다. 한 언어가 빠졌으면 부분 가져오기를 수락해야 하며, 빠진 번역을 만들어 내지 않는다.
  - **목록:** 게이트웨이에 아직 목록 API가 없으므로, [목록 불러오기]는 "(더미)"로 표시된 고정 샘플 항목을 보여 준다.

## 다시 실행할 때

`harness.toml`이 있으면 요약을 보여 주고, 파일이 설정과 일치하는지 검증한다. 이 모드에서는 변경을 적용하지 않는다. 스킬 추가·갱신은 2단계 기능이다. 같은 초기화를 반복해도 블록, 스킬, ignore 규칙이 중복되지 않는다.

## 복구

- 기존 파일을 바꾸기 전에 `.harness/backups/<apply-id>/`에 사본을 남긴다.
- 쓰기가 실패하면 이미 쓴 파일을 되돌리고, 새로 만든 파일과 빈 폴더를 지운다. 되돌리지 못한 항목은 목록으로 보여 주며, 성공으로 기록하지 않는다.
- 비정상 종료로 `.harness/apply.lock`이 남으면, 사용자가 지울 때까지 적용을 거부한다. 다른 실행이 없을 때만 지운다.
- 도구는 커밋·푸시를 하지 않는다. 제외 대상 경로를 Git이 이미 추적 중이면 `git rm --cached`를 직접 실행하라고 안내한다.
