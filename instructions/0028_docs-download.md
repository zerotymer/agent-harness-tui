## 목표
프로젝트 구성의 `docs` 항목을 골라 `https://`로 내려받아 `<references>/<filename>`에 저장하고 `harness.lock.json`에 기록한다.

## 범위
- 포함:
  - 카탈로그 화면에서 문서 선택(Enter·Space). 상태: 내려받기 가능, 선택됨, 내려받음, 사용 불가(참조 문서 경로 없음)
  - 미리보기 직전에 내려받기(명시적 User-Agent, 30초 제한). 고르는 동안에는 받지 않는다
  - `sha256` 없음: 경고 후 저장. 불일치·실패: 미리보기에 보고하고 제외, 나머지는 적용
  - 내용이 다른 기존 파일은 충돌(소유 파일, 덮어쓰지 않음)
  - `harness.lock.json` `docs`: `{id, url, path, hash}`, 비어 있으면 쓰지 않음. 내려받은 문서는 다시 고를 수 없다
  - 초기화된 프로젝트의 추가 작업(스킬 추가 화면의 카탈로그)에서도 쓸 수 있다
- 제외: 내려받은 문서의 갱신·삭제, skills 갱신, dynamic skills
