## 목표
소스 연결 경계(목록·검색·미리보기·가져오기)를 두고, 로컬 디렉터리 소스와 `md.zerotymer.net` 위키 게이트웨이 소스를 구현해 선택한 스킬을 `.skills/`로 가져온다.

## 규칙 구분
- 아래 요구사항은 TUI가 **대상 프로젝트에 적용하는 제품 동작**이다. 이 저장소의 작업 규칙(`CLAUDE.md`, `.skills/`)과 혼동하지 않는다.
- 테스트는 임시 디렉터리에 대상 프로젝트를 만들어 검증한다. 이 저장소의 `instructions/`, `.gitignore`, 지침 파일을 픽스처로 쓰지 않는다.

## 범위
- 포함:
  - 공통 경계: 소스별로 지원하는 동작(목록·검색·미리보기·가져오기)과 미지원 사유를 노출
  - 로컬 디렉터리 소스: `SKILL.md`가 있는 디렉터리를 스킬 패키지로 인식, 동봉 파일 포함
  - 위키 게이트웨이 소스 (`https://md-gw.zerotymer.net`, REST):
    - `GET /pages/by-uuid?uuid=<uuid>[&type=<type>]`, `Authorization: Bearer <GATEWAY_TOKEN>`. `type`은 사용자가 경로 접두어를 줄 때만 전달
    - 토큰은 환경변수 `GATEWAY_TOKEN`에서만 읽음. 설정·lock·지침·미리보기·로그에 값 기록 금지 (설정에는 환경변수 이름만)
    - 응답 `pages.en.content` → `SKILL.md`, `pages.ko.content` → `SKILL_ko.md`, 내용은 가공하지 않고 그대로 저장
    - 한 언어만 있으면 사용자가 부분 가져오기를 수락할 때만 진행, 없는 번역본 생성 금지
    - 빈 `content`는 경고하고 파일을 쓰지 않음
    - 프런트매터는 해석·가공하지 않음. `.skills/<name>/`의 이름은 가져올 때 사용자가 입력 (기본값: `title` 슬러그)
    - 오류: 토큰 없음, 게이트웨이 연결 불가(URL·UUID 표시), 401/403, `PAGE_NOT_FOUND`를 구분해 명확히 보고
    - 시간 제한 있는 HTTP 요청. 캐시는 두지 않음 (도입 시 저장 시점 표시·사용자 선택 필요)
    - Wiki.js GraphQL 직접 호출, `md.zerotymer.net` HTML 수집 금지
    - 목록·검색은 더미: 네트워크 호출 없이 코드 내 고정 샘플 항목을 반환, 화면에 "더미"로 표시, 항목 선택 시 UUID 가져오기로 연결. 실제 규약이 오면 별도 지시서로 교체
  - 조회는 사용자 요청 시에만 (화면 다시 그릴 때 조회하지 않음)
  - 가져오기: `.skills/<name>/`에 기록. `harness.lock.json`에 소스(`md.zerotymer.net` 또는 로컬 경로), UUID, `type`, 언어별 파일·`contentHash`, 가져온 파일 목록 기록 (이 저장소 `.skills/*/source.json` 형태 참고)
  - 동봉 스크립트·템플릿 보존, 실행하지 않음 (게이트웨이는 Markdown만 제공)
  - 목적지를 벗어나는 패키지 경로(`..`, 절대 경로, 외부를 가리키는 심볼릭 링크) 거부
  - 기존 무관한 스킬 덮어쓰기 금지 (충돌)
  - 원격 변경을 이유로 설치된 스킬을 바꾸지 않음
- 제외:
  - 게이트웨이 MCP 인터페이스 (TUI는 REST 사용)
  - 게이트웨이 쓰기(업로드·패치), 실제 목록·검색 (규약 미제공)
  - 프런트매터 해석·가공 (추후 지시)
  - 오프라인 캐시
