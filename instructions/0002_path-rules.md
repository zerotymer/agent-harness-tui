## 목표
프로젝트 루트 결정, 경로 정규화·검증, 관리 경로 표를 구현한다. 이후 모든 쓰기는 이 모듈을 거친다.

## 규칙 구분
- 아래 요구사항은 TUI가 **대상 프로젝트에 적용하는 제품 동작**이다. 이 저장소의 작업 규칙(`CLAUDE.md`, `.skills/`)과 혼동하지 않는다.
- 테스트는 임시 디렉터리에 대상 프로젝트를 만들어 검증한다. 이 저장소의 `instructions/`, `.gitignore`, 지침 파일을 픽스처로 쓰지 않는다.

## 선행 조건
- 0001

## 범위
- 포함:
  - 현재 실행 디렉터리 = 프로젝트 루트. 상위 탐색·루트 변경·브랜치 전환·`git init` 없음
  - 상대 경로는 실행 파일·설정 파일 위치가 아니라 프로젝트 루트 기준으로 해석
  - 비교용 정규화, 공유 설정에는 이식 가능한 프로젝트 상대 경로(`/` 구분자) 저장
  - 입력 지원: 공백, 한글, Windows 드라이브 경로 (루트 내부 절대 경로는 상대 경로로 변환)
  - 거부: `..`·심볼릭 링크 해석 결과의 루트 이탈, 중복 목적지, 관리 디렉터리 간 중첩, 기존 파일과의 충돌
  - 경로 표: `instructions/`(고정, `.completed/`·`completed.log` 포함), `references/`(변경 가능), `.output/`(변경 가능, 점으로 시작 필수), `.skills/`(고정), `agent.db`(사용 여부만)
  - Windows 숨김 속성: Windows에서는 적용 시도, 적용 불가 시 이유를 결과에 표시. 이름 앞 점만으로 숨김 처리됐다고 보지 않음
- 제외:
  - 다른 worktree 상태 탐색·복사·동기화

## 작업 항목
1. 루트·경로 타입 정의
2. 정규화·검증 함수와 거부 사유(오류 종류) 정의
3. 경로 표와 고정/변경 가능 규칙
4. 테스트: 이탈(`..`, 심볼릭 링크), 중복, 중첩, 파일 충돌, 공백·한글 경로, 점 접두어 규칙, Windows 드라이브 경로 파싱
