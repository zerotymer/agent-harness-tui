## 목표
하나의 하네스 설정에서 대상 프로젝트용 `AGENTS.md` / `AGENTS_ko.md`, `CLAUDE.md` / `CLAUDE_ko.md` 관리 블록과 지시서 디렉터리를 생성한다.

## 규칙 구분
- 아래 요구사항은 TUI가 **대상 프로젝트에 적용하는 제품 동작**이다. 이 저장소의 작업 규칙(`CLAUDE.md`, `.skills/`)과 혼동하지 않는다.
- 테스트는 임시 디렉터리에 대상 프로젝트를 만들어 검증한다. 이 저장소의 `instructions/`, `.gitignore`, 지침 파일을 픽스처로 쓰지 않는다.

## 범위
- 포함:
  - 선택한 에이전트별 지침 파일 (단수 `AGENT.md`가 아닌 `AGENTS.md`)
  - 같은 구조화된 설정에서 영/한 지침을 생성해 정책 동등성 유지
  - 지침 내용: 경로 의미, 지시서 수명주기(파일 규칙, UUID·상태, `.completed/<UUID>.md` 이동, 명시적 완료), 로그 정책(`UUID | 내용 | 오프셋 포함 일시`, 덮어쓰기 금지, 병합 충돌 노출), 참조 문서·스킬 위치와 용도, 산출물 정책, 백로그 옵션, Git 정책
  - 스킬 본문은 합치지 않고 용도·위치만 안내
  - `instructions/`, `instructions/.completed/` 생성, `completed.log`는 없을 때만 빈 파일 생성 (기존 로그 보존, 초기화를 이벤트로 기록하지 않음)
  - `agent.db`는 옵션만 기록, 파일·스키마 생성 없음
  - 도구 자체는 지시서 실행·완료 처리를 하지 않음
  - 지침은 정책 표현이며 권한을 강제한다고 쓰지 않음
- 제외:
  - 스킬 배치 안내의 에이전트별 세부 (0008에서 추가)
